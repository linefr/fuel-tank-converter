# CM to Litres Converter

A simple Python project that converts tank measurements from centimetres to litres using calibration data stored in SQLite.

## Project Status

🚧 Work in progress — Week 1

Currently working with PDF extraction and CSV files.

**Expected result:** A CSV file with centimetres and litres columns
extracted using pdfplumber
organized with pandas
validated against the original PDF
